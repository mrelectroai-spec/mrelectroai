# كورس «الطاقة الشمسية بالمختصر المفيد»

نفس نظام كورس الكتاب الأول، على 32 قاعدة × 10 أسئلة = 320 سؤال، وبينفتح بعد ما يخلّص كورس الكتاب الأول.

- كل سؤال بيغلط فيه الطالب بيرجعلو لحتى يجاوبو صح، والغلط ما بيكشف الجواب الصح.
- بعدها لازم يجاوب 5 أسئلة صح ورا بعض (اختبار البصم) لتنفتح القاعدة يلي بعدها.
- كل سؤال إلو نوع: مفهوم، موقف، عطل، أرقام، مخطط، سلامة.
- بكل قاعدة: زر «شوف رسمة القاعدة» (من الكتاب)، وزر «جرّب القطعة بالمختبر» إذا إلها قطعة.
- التقدّم بينحفظ عالتلفون، وبالآخر ملخص PDF وشهادة بيتبعتوا لأنور عالواتساب.
- التحدّي (الخصم عالكتاب) مطفي. لتشغيلو: `window.COURSE_CONFIG = { challenge: true }` قبل app.js، وعدّل الأسعار بـ app.js.

## الملفات
- `questions.js` الأسئلة (الجواب الأول بكل سؤال هو الصح، والموقع بيخلطهن)
- `figs.js` رسمات الكتاب (بتنولّد من ملفات الكتاب)
- `app.js` منطق الكورس والـ PDF والواتساب
- `style.css`، `index.html`، `cover.jpg`
