# كورس «الكهرباء بالمختصر المفيد»

موقع تفاعلي بيسأل الطالب 10 أسئلة على كل قاعدة من الـ 18 قاعدة بالكتاب.

- كل سؤال بيغلط فيه بيرجعلو لحتى يجاوبو صح.
- القاعدة بتخلص بس يجاوب كل أسئلتها صح (اختبار «5 صح ورا بعض» انلغى).
- وضع الأستاذ (كلمة سر بالإعدادات بالتطبيق) بيخلّي أنور يتخطّى القواعد، وما بتنبعت نتايجو.
- ما بتنفتح القاعدة يلي بعدها قبل ما يبصم يلي قبلها.
- التقدم بينحفظ عتلفون الطالب، فإذا سكّر الصفحة بيكمّل من وين وقف.
- بالآخر بيعمل ملخص PDF (شهادة + جدول الغلطات + نقاط الضعف) وبيبعتو عالواتساب لأنور: ‎+961 79 434 479.

## الملفات
- `index.html` الصفحة
- `style.css` الشكل
- `app.js` منطق الكورس والـ PDF والواتساب
- `questions.js` الـ 180 سؤال (لتعديل سؤال أو جواب، عدّل هون: الجواب الأول بكل سؤال هو الصح)
- `cover.jpg` صورة الغلاف
